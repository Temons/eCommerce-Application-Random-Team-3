# E-Commerce Application

This project is a modern E-Commerce platform built with a clean and maintainable code structure, leveraging tools such as ESLint, Prettier, Husky, and Jest.

## Features

- **ESLint** for linting and enforcing coding standards.
- **Prettier** for automatic code formatting.
- **Husky** for Git hooks, ensuring pre-commit and pre-push checks.
- **Jest** for unit testing to ensure reliability.

## Setup

### 1. Clone the repository:

git clone https://github.com/Temons/eCommerce-Application-Random-Team-3.git
cd ecommerce-application

### 2. Install dependencies:

npm install

### 3. Run the development environment:

npm run dev

### 4. Run tests:

npm test

## Configuration

### ESLint

We use ESLint with the following configurations:

- Linting for JavaScript, TypeScript, and JSX/TSX files.
- Custom rules for consistent coding styles.

### Prettier

Prettier is set up to automatically format your code on save with the `.prettierrc` configuration file.

### Husky

Husky is configured for pre-commit and pre-push hooks, ensuring that linting and formatting are applied before any code is committed or pushed.

### Jest

Unit tests are written in Jest and are set up to test core functionality.

## Testing

To run the tests, use the following command:

npm run test
